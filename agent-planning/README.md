## 当前研究判断

### 最新讨论：Agent 安全

已形成专题问题地图，未确定投入：意图与控制流、身份与委派、执行隔离、记忆可信、工具供应链、多 agent 传播、安全评估与处置。

最主要的工程痛点判断是：合法工具被用于未授权目的；信息经过压缩、记忆和委派后丢失来源；安全限制与正常任务效用冲突；配置声明与实际执行边界不一致；发现污染后难以清除派生影响。此处不是事故频率排名。

技术方向包括模型抗注入、模型之外的信息流与权限强制、隔离与凭证代理、记忆来源和撤销、委派收缩、联合安全/效用评估。

硬件关联单独讨论：CPU 虚拟化与 I/O 隔离、AMD SEV-SNP、Arm CCA、GPU 机密计算和远程证明，分别支撑执行隔离及抵御不可信基础设施；不直接解决提示注入或用户意图授权。GPU/AMD/Arm 不属于同一级分类。详细来源、支持限制和主流产品对照见上方安全专题链接。

### 第一轮四方向研究

第一轮研究的初步判断：sandbox、memory/context、harness 和 multi-agent 正在围绕三个问题汇合——agent 如何持续可靠地工作、如何从经历中改进、如何有效分工。这是助手基于公开材料的综合推断，尚未形成团队投入决策。

资料核验截至 2026-09-06，未复现实验；仓库能力声明、论文实验结果和规划推断应分别看待。

### Sandbox：执行环境的整个生命周期

公开进展：

- **AgentENV** 当前强调大规模 agentic RL 环境、镜像按需加载、增量快照、fork 和资源密度。[官方仓库](https://github.com/kvcache-ai/AgentENV)
- **CubeSandbox** 在推进快照回滚、跨节点暂停恢复、出网控制和凭证代理。[官方仓库](https://github.com/TencentCloud/CubeSandbox)
- **E2B、Modal** 提供持久化与快照能力，但保存状态、恢复语义和成熟度不同。[E2B SDK](https://github.com/e2b-dev/E2B/blob/main/packages/js-sdk/src/sandbox/index.ts)、[Modal 快照文档](https://modal.com/docs/guide/sandbox-snapshots)

| 问题主线 | 真正需要回答的问题 |
|---|---|
| 生命周期成本 | agent 等模型、等用户、暂停再恢复时，如何释放资源并保持可用？ |
| 状态恢复与分叉 | 文件、进程、连接分别恢复到哪里？分叉后的状态如何独立演进？ |
| 执行权限边界 | 文件隔离之外，网络、凭证和外部工具权限如何控制？ |
| 大规模环境供给 | 大量不同镜像、长时间运行与高并发，如何兼顾启动、存储和调度？ |

隔离方式需要匹配场景。Anthropic 的工程报告讨论进程沙箱、容器、VM，以及文件系统、网络和凭证边界，没有一种方案覆盖所有产品。[工程报告](https://www.anthropic.com/engineering/how-we-contain-claude)

**规划推断：需要区分“训练环境基础设施”和“在线 agent 执行环境”两类投入。** 前者更关注批量环境、重置、分叉和吞吐；后者还关心持久工作空间、尾延迟和用户操作的连续性。它们可以共享技术，但评价标准不应混用。

**接口研究问题：恢复 sandbox 快照，并不会自动撤销已经发生的外部操作。** 文件恢复了，但任务日志、长期记忆和外部系统可能已经前进。这里需要 sandbox 与 harness 共同定义恢复语义。此项为待验证的设计问题，不是已确认的项目缺陷。

### 其他方向的当前摘要

以下摘要对应上方两份研究文档中的证据与分析，细节和来源见全文。

| 方向 | 已记录的问题主线 | 尚待验证 |
|---|---|---|
| Memory/context | 上下文供给、经验迁移、更新遗忘、来源信任、实际任务收益 | 结构化经验能否优于无记忆及原始轨迹搜索，并适应环境变化 |
| Harness | 长任务接续、故障恢复、完成验证、模型适配、失败归因 | 中断后能否仍正确交付，模型升级后哪些策略应删除 |
| Multi-agent | 委派、上下文分配、协作正确性、终止与预算 | 对比充分优化的单 agent 是否有同预算净收益 |
| Agent 安全 | 意图与权限、隔离、记忆污染、插件工具信任、协作与恢复 | 目标威胁模型、控制效果与正常任务代价 |
| DeepSeek Harness | 插件化、追加式 session 日志、恢复分叉、多种执行模式 | 与 DeerFlow 的代码级对照、故障语义及同条件评测 |
| 横向评估 | 统一任务、模型、预算、环境与轨迹，做消融及归因 | 区分各组件增益与额外计算投入 |

目前三个候选研究主题为：可恢复且可验证的长任务执行；可迁移且可纠错的经验积累；按任务结构调整的协作策略。均未批准为资源投入路线。
